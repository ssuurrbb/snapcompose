# Структура ассетов (экспорт из Figma)

Сюда кладём **векторные** файлы из Figma. Скриншоты оставляем в старых папках `библиотека компонентов/` и `примеры композиций/` — это только референс.

## Дерево

```
assets/
├── library/                 ← отдельные объекты-компоненты (основа сервиса)
│   ├── L/
│   │   ├── main/            ← главные (цветные), размер L
│   │   └── background/      ← фоновые (монохром), размер L
│   └── S/
│       ├── main/            ← главные, размер S
│       └── background/      ← фоновые, размер S
├── palettes/                ← описание 3+ цветовых схем
├── planes/                  ← плоскости фона (если экспортируются отдельно)
├── examples/                ← целые эталонные композиции (для сверки)
│   ├── square/
│   ├── horizontal/
│   └── vertical/
└── reference/               ← опционально: PNG превью объектов (не для экспорта итога)
```

## Именование файлов (важно)

Один и тот же объект во всех папках — **одно и то же имя**:

```
book.svg
phone.svg
puzzle.svg
headphones.svg
lamp.svg
vase.svg
wallet.svg
folder.svg
pen.svg
coin.svg
```

Актуальный инвентарь: `library/_inventory.md`.

Правила:
- латиница, `kebab-case` или `snake_case` — на выбор, но **одинаково везде**
- без суффиксов `-L`, `-main` в имени файла (размер и роль уже в пути папки)
- формат: **SVG** (не PNG)
- если в Figma объект — группа/фрейм, экспортируй **целиком один SVG на объект**

Пример соответствия:

| Объект | L main | L background | S main | S background |
|--------|--------|--------------|--------|--------------|
| Книга | `library/L/main/book.svg` | `library/L/background/book.svg` | `library/S/main/book.svg` | `library/S/background/book.svg` |

Если какого-то варианта нет в макете — папку оставляй пустой или не клади файл; потом отметим в инвентаре.

## Палитры (`palettes/`)

Положи одно из:
- `palette-1.svg` / `palette-2.svg` / `palette-3.svg` (если в Figma это свотчи), **или**
- скрин/экспорт свотчей + заполни `palettes/palettes.json` (шаблон ниже)

В JSON отметь, какие цвета **только для плоскости фона**, какие — для объектов.

## Плоскости (`planes/`)

Если в примерах есть отдельный прямоугольник-«пол»/фон сцены:
- `plane-square.svg`
- `plane-horizontal.svg`
- `plane-vertical.svg`

или один `plane.svg`, если формат меняется только размером холста.

## Примеры композиций (`examples/`)

Целиком собранные сцены из раздела «варианты на разных форматах» — **SVG**, если получается выгрузить.
Нужны для сверки автораскладки, не как библиотека деталей.

Именование:
- `main-only-01.svg` — только главные объекты
- `with-bg-01.svg` — с фоновыми объектами

## Как выгружать из Figma (кратко)

1. Открой файл → раздел библиотеки компонентов.
2. Для каждого объекта: выделить фрейм/группу объекта → справа Export → **SVG** → Export.
3. Повтори для L/S и main/background.
4. Палитры и 2–3 эталонные композиции — отдельно.
5. Положи файлы в папки выше с согласованными именами.

### Настройки экспорта SVG (желательно)
- Outline text — если есть текст (скорее нет)
- Include "id" attribute — можно включить
- Не Flatten / не растрировать эффекты без нужды

## Чеклист перед тем как сказать «готово»

- [ ] В `L/main` и `S/main` одни и те же имена файлов
- [ ] В `L/background` и `S/background` те же имена (где варианты есть)
- [ ] Только SVG в `library/`
- [ ] 3 палитры описаны или экспортированы
- [ ] Хотя бы 2–3 example SVG (или PNG, если SVG целиком неудобно)
