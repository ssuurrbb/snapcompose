# Примеры композиций Snapcompose

Сюда положите **2–3 SVG**, экспортированные кнопкой «Скачать SVG» из сервиса.

Рекомендуемый набор для сдачи:
1. Сценарий 1 (метафора) — квадрат
2. Сценарий 2 (имена) — горизонталь
3. Ручная доводка / другая палитра — вертикаль

По желанию рядом положите PNG/JPG-скрины холста.
